Pump.fun launch-sniper paper-trading bot: buys a launch in its first few slots only if it clears a rug filter (real SOL in range, creator's own buy small, few distinct buyers, creator has not sold), then exits fast on take-profit, stop-loss, a short holding cap, or a creator sell. Tiny probe round trips keep the run above the 20-coin guardrail on the 6-hour final window. Paper trading only — no real funds.

## Run it

```sh
node main.ts
```
